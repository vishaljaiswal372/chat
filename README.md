## 🚀 Features

- 💬 Real-time Messaging with [Stream.io](https://getstream.io)
- 🎥 One-on-One and Group Video Calls using Stream Video SDK
- 👥 Group Chat & Direct Messages
- 🔐 JWT-based Secure Authentication
- 🖼️ User Avatars & Profile Handling
- ⚡ Modern UI/UX with Responsive Design
- 🎨 Optional Dark Mode Support

## 🛠️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/vishaljaiswal372/chat.git
cd chat

```

### 2. Install dependencies
npm install
---

### 3. Set environment variables
Create a .env file in the root directory and add the following:
```bash
REACT_APP_STREAM_API_KEY=your_stream_api_key
REACT_APP_STREAM_API_SECRET=your_stream_secret
REACT_APP_STREAM_APP_ID=your_stream_app_id
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret

```

### 4. Run the application

```bash
npm run dev
```
